# merki.store — статическая копия

Зеркало сайта https://merki.store/ (Tilda), снятое 2026-09-14 скриптом `_mirror.py`, затем доработанное вручную.

- `index.html` — главная (все разделы: товары, отзывы, доставка, обо мне, FAQ, контакты)
- `order/index.html` — страница «Заказать» (URL `/order/`) (WhatsApp / email); на неё ведут все кнопки «Заказать …»
- `assets/static`, `assets/thb` — картинки, CSS, JS с tildacdn
- `assets/fonts`, `assets/gfonts` — Roboto (Google Fonts) локально
- `originals/` — исходные фото полного размера (2500px) с Tilda; в `assets/` лежат ужатые до 1200px версии, чтобы страница не тормозила при скролле

Все пути относительные: можно открыть `index.html` напрямую или отдать папку любым статическим хостингом.

Отличия от оригинала:
- удалены счётчики (Яндекс.Метрика, Tilda stat) и футер «Made on Tilda»
- удалены страницы заказа с формами (`purchase-*`, `male-shorts`) — вместо них `/order/`

`_mirror.py` снимает копию заново с нуля (без этих правок) — на случай, если понадобится.
